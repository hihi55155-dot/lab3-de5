Kiến trúc đa nhiệm FreeRTOS trên ESP32

Core 0 — Task truyền data

Kết nối WiFi, nhận dữ liệu từ hàng đợi data Queue và publish lên MQTT Broker.

Core 1 — Task đọc data & Task cảnh báo

Đọc MPU6050, xuất Serial, đẩy vào data Queue & data Alert để kích hoạt Còi/Đèn.
